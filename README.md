# Smart Parking System

Smart Parking Management System to book and manage parking slots in real-time.

## Features
- Real-time Slot Availability
- Online Slot Booking
- Vehicle Entry & Exit Management
- Automatic Fare Calculation
- Admin Dashboard & Reports

## Tech Stack
- Backend: Java, Spring Boot, REST API
- Frontend: HTML, CSS, JavaScript
- Database: MySQL
- Tools: Git, GitHub, Postman

## How It Works
1. User selects parking location
2. Checks available slots in real-time
3. Books slot and gets confirmation
4. Fare calculated on exit based on duration
